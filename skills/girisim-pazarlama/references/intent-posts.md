# Buying-intent posts: find them and draft replies

Find customers by intent signal, not from lists. A mass template creates no intent and burns reputation (G7).

## Steps

1. **List the phrases buyers use (G7):**
   - asking for a recommendation ("can anyone recommend a tool for …")
   - "how do I …"
   - "looking for an alternative to …"
   - complaints about the tool they use now
2. **Scan** the relevant subreddits, forums and comment sections with these phrases. Ignore everything else.
3. **Draft a short reply** for each matching post (G8, G9):
   - solve the question first;
   - refer back to their own words;
   - mention the product only if it is actually needed.
4. **Pace:** aim for one good reply a day. Precision, not volume (G9).
5. **Split the work:** an agent may scan and draft; the user writes the final reply, approves it and sends it (G9).

## Guardrails

- Never post or send a reply yourself.
- No auto-reply bots, mass cold messages or the same text pasted in several places (G15). Follow each community's rules.
