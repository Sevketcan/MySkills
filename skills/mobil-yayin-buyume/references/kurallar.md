- **Android para getiriyor mu?** samlecan "Android para getirmiyor" fikrini denemeden kabul etmemeyi söylüyor. RevenueCat'in medyanlarına göre install başı gelir iOS'ta Android'in ~2,6 katı (gursuyaman aktarımı). Çelişki değil, bütçe meselesi: Android ancak CPI'ı eşiğin altındaysa aynı bütçeyle daha çok getirir (K56, K57).
