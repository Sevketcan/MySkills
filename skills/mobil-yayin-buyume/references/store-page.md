# Store page (ASO)

## Steps

1. **Keywords:** consider keywords that match intent and are reachable, instead of saturated, high-difficulty ones (K26).
2. **Custom Product Pages:** consider one per traffic channel, so a user who arrives from an ad sees the ad's promise on the page (K26).
3. **Screenshots:** one value proposition per screen, little text, simplified from a real screen (K12). Duo screenshots: [foldable-screens.md](foldable-screens.md). The App Store preview video is produced with `video-icerik-uretimi`.
4. **Metadata in the repo:** consider keeping the text and images in the repo and sending them with `asc` (iOS) or `gpc` (Android), previewing changes with `--dry-run` first (K29).
5. **Plan acquisition separately:** assume ASO alone won't be enough (K24); see [web-funnel-acquisition.md](web-funnel-acquisition.md). The sources disagree on how much ASO matters; the conflict is listed in [kurallar.md](kurallar.md).

The sources don't cover the App Store keyword field's technical details; use Apple's current documentation for those.
